## Overview

TeoriOnline.dk is a digital learning platform I founded for preparing the Danish driving theory test. It provides theory materials, practice exams, progress tracking, and guides aligned with the official test.

## Key contributions

- Designed and implemented REST API endpoints for integrations with external systems
- Developed modular React components with a focus on reusability and maintainability
- Responsible for the software architecture of the platform, with a focus on scalability and modularity

## Tech stack

Next.js, React, TypeScript, REST API
