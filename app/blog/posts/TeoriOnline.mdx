## Overview

[TeoriOnline.dk](https://teorionline.dk) is a digital learning platform I
founded for preparing the Danish driving theory test. It provides theory
materials, practice exams, progress tracking and guides aligned with the
official test.

## What I built

- The software architecture of the platform, designed for scalability and
  modularity
- REST API endpoints for integrations with external systems
- Modular React components with a focus on reusability and maintainability
