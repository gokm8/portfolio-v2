## Overview

AsteroidsFX is the classic Asteroids game, used as a vehicle for modular
software architecture. It is written in Java with JPMS, JavaFX 21 and Spring
Framework 6, and structured as a Maven multi-module build where every concern
lives in its own module.

## What I built

- A modular Asteroids game in Java using JPMS, JavaFX and Spring
- A Maven multi-module build with a clear separation of concerns
- A plugin-based architecture following CBSE principles, so components can be
  added or swapped without touching the core

A recording of the game is available as a
[demo video](https://www.youtube.com/watch?v=pes3ECHNUdA).
