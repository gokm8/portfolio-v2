## Overview

AsteroidsFX is a modular Asteroids game developed in Java using JPMS, JavaFX, and Spring Framework, structured as a Maven multi-module build with separation of concerns.

## Key contributions

- Developed a modular Asteroids game in Java using JPMS, JavaFX, and Spring
- Implemented the project as a Maven multi-module build with separation of concerns
- Designed a plugin-based architecture following CBSE principles for extensible components

## Tech stack

Java, JPMS, Maven, JavaFX 21, Spring Framework 6
