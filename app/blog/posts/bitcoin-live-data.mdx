## Overview

A fullstack dashboard that pulls live cryptocurrency data from an external API,
processes it on the server and presents it as interactive visualizations that
update in real time.

## What I built

- Integration with an external cryptocurrency API for live data retrieval and
  processing
- A fullstack architecture with separate frontend, backend and database layers
  (React, Node.js with Express.js, MySQL)
- Interactive data visualizations in React with real-time updates

A recording of the dashboard is available as a
[demo video](https://www.youtube.com/watch?v=PYco5e2GVh8).
