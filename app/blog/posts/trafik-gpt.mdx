## Overview

TrafikGPT is a chat assistant for Danish traffic information with streaming responses, source-backed web search, and configurable model selection across multiple LLM providers.

## Key contributions

- Developed a chat assistant with streaming responses via Vercel AI SDK
- Implemented source web search with Exa against official Danish traffic sources
- Integrated multiple LLM providers via Vercel AI Gateway with configurable model selection

## Tech stack

Next.js, React, Tailwind, Vercel AI SDK, Vercel AI Gateway, Exa
